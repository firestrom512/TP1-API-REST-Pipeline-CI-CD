# API REST - Annuaire d'étudiants
TP de CI/CD : Flask, pytest, Ruff et GitHub Actions.
## Commandes du projet (depuis la racine, environnement virtuel activé)- Démarrer le serveur : `python -m flask --app src.app run`- Lancer les tests : `python -m pytest -q`- Lancer le linter : `python -m ruff check .`
## Installation
`python -m pip install -r requirements.txt
